# CWC Windows Codex Preview

This is a cleaned preview distribution for Windows Codex desktop users. It is not the public OpenAI Plugins Directory package.

The package contains no runtime state, pairing records, conversation evidence, credentials, or user task history. Runtime state is created under the installing user's normal Codex state directory.

Required environment:

- Codex desktop with the built-in thread tools `list_threads`, `send_message_to_thread`, and `read_thread`.
- Windows PowerShell, Python 3, and Node.js available to the local execution environment.

The current feature boundary is Codex desktop on Windows. It does not claim support for ordinary ChatGPT chats, macOS, Linux, Codex CLI, or Codex cloud.
